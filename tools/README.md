# fill.mjs — 가사 JSON의 pron / trans 자동 채우기 도구

`jp-lyrics-player` 프로젝트의 곡 JSON(`songs/*.json`)에서 **비어 있는** `pron`(일본어 → 한글 발음)과
`trans`(일본어 → 한국어 번역) 항목을 자동으로 채워 주는 PC 전용 Node.js CLI입니다.

- `pron` : 일본어 원문(`orig`, 한자+가나 혼용)을 형태소 분석해 가타카나 발음을 얻고, 스크립트 안에
  직접 정의한 **가타카나 → 한글 변환표**로 한국인이 읽어서 근사하게 발음할 수 있는 한글로 바꿉니다.
- `trans` : 웹 번역 API로 일본어 문장을 한국어로 번역합니다. 기본 엔진은 **MyMemory**이며 API 키가 필요 없습니다.

이 도구는 프로젝트 실행에 관여하지 않는 **개발용 보조 스크립트**입니다. `tools/` 폴더 안에서만 동작합니다.

---

## 설치

```
cd tools
npm install
```

- `cd tools` : 이 도구 폴더로 이동합니다. (프로젝트 루트에는 `package.json`이 없습니다. 의존성은 전부 `tools/` 안에만 있습니다.)
- `npm install` : 아래 의존성을 설치합니다. 최초 1회만 실행하면 됩니다.

설치되는 의존성(정확한 버전 고정):

| 패키지 | 버전 | 용도 |
| --- | --- | --- |
| `kuromoji` | `0.1.2` | 순수 JS 일본어 형태소 분석기. 사전 데이터(`dict/`)가 패키지에 포함되어 있어 **오프라인**으로 동작하고 Windows에서도 추가 빌드 도구 없이 설치됩니다. |

> `kuroshiro` 대신 `kuromoji`를 직접 쓴 이유: `kuroshiro`는 래퍼 계층이 하나 더 있고 최신 Node에서
> 설치·실행 이슈가 종종 보고됩니다. `kuromoji`는 토큰마다 `pronanciation`(가타카나, 장음이 `ー`로 정규화됨)을
> 바로 주기 때문에 장음 처리가 쉽고, 조사 `は`/`へ`의 실제 발음(`ワ`/`エ`)도 그대로 얻을 수 있습니다.
> 로마자 중간 단계 없이 **가타카나 → 한글**로 바로 변환합니다.

`wanakana` 등 추가 라이브러리는 쓰지 않습니다. 한글 변환표는 `fill.mjs` 안의 `KANA` 객체에 있습니다.

## 사용법

```
node fill.mjs <파일 또는 폴더> [옵션]
```

| 옵션 | 설명 |
| --- | --- |
| `--out <file>` | 원본을 고치지 않고 결과를 `<file>`에 저장합니다. (폴더 입력 시 무시) |
| `--dry` | 바뀔 내용만 출력하고 **아무 것도 쓰지 않습니다**. |
| `--pron-only` | `pron`만 채웁니다. (네트워크 접속 없음) |
| `--trans-only` | `trans`만 채웁니다. (kuromoji 사전 로딩 없음) |
| `--force` | 이미 값이 있는 `pron`/`trans`도 덮어씁니다. (기본값: 덮어쓰지 않음) |
| `--engine <name>` | 번역 엔진: `mymemory`(기본), `deepl`, `google` |
| `-h`, `--help` | 도움말 |

### 예시

```
# 곡 하나를 제자리에서 수정 (원본은 napori.json.bak 로 백업됨)
node fill.mjs ../songs/napori.json

# songs 폴더의 모든 *.json 을 발음만 채움 (네트워크 미사용, 빠름)
node fill.mjs ../songs --pron-only

# 무엇이 바뀔지 미리보기만
node fill.mjs ../songs/napori.json --dry

# 원본 대신 별도 파일로 저장, 구글 엔진 사용
node fill.mjs ../songs/napori.json --out ./napori.filled.json --engine google

# DeepL 사용 (환경변수로 키 전달)
DEEPL_API_KEY=xxxxxxxx node fill.mjs ../songs/napori.json --engine deepl
```

Windows PowerShell에서 환경변수를 넘길 때:

```
$env:DEEPL_API_KEY = "xxxxxxxx"; node fill.mjs ../songs/napori.json --engine deepl
```

- `$env:DEEPL_API_KEY = "..."` : 현재 세션에만 유효한 환경변수를 설정합니다.
- `;` 뒤 명령이 이어서 실행됩니다.

## 동작 규칙 (중요)

- **수동 입력이 우선입니다.** 이미 비어 있지 않은 문자열인 `pron`/`trans`는 절대 건드리지 않습니다.
  `""`, 키 없음, `null`인 경우에만 채웁니다. (`--force`를 주면 예외적으로 덮어씁니다.)
- `t`, `orig`, `title`, `artist`, `youtubeId`, `offset`, 그리고 `lines` 배열의 순서는 **절대 바꾸지 않습니다.**
  `t`는 숫자 표기(예: `36.20`의 뒤 0)까지 원문 그대로 보존합니다.
- 제자리 수정 전에는 항상 `<파일명>.bak` 백업을 만듭니다. (`--out` 사용 시에는 백업을 만들지 않습니다.)
- 번역은 같은 실행 안에서 **원문 문자열 단위로 캐시**합니다. (후렴처럼 반복되는 줄은 1번만 호출)
- 네트워크 호출 사이에 약 **400ms** 간격을 둡니다.
- 한 줄 번역이 실패하면 그 줄은 **비워둔 채로** 넘어가고 실패 수를 셉니다. (전체가 멈추지 않음)
- `orig`가 ASCII(라틴 문자)로만 이루어진 줄(예: `"Oh right, oh right"`)은 `pron`·`trans` 모두 원문을 그대로 씁니다.
- 실행이 끝나면 요약 줄을 출력합니다: 총 줄 수 / pron 채움 / trans 채움 / 건너뜀(값 있었음) / 실패.

## 번역 엔진과 키

| 엔진 | 키 필요 여부 | 비고 |
| --- | --- | --- |
| `mymemory` (기본) | **불필요** | `https://api.mymemory.translated.net`. 익명 사용은 하루 사용량 제한이 있습니다. 품질은 보통 수준. |
| `google` | 불필요 | 비공식 엔드포인트(`translate.googleapis.com/translate_a/single`). 차단·형식 변경 가능성 있음. |
| `deepl` | **필요** (`DEEPL_API_KEY`) | DeepL API Free (`https://api-free.deepl.com/v2/translate`). 품질이 가장 좋음. |

기본 경로(`mymemory`)는 **API 키가 전혀 필요 없습니다.** `--pron-only`로 쓰면 네트워크 접속도 없습니다.

## 가나 → 한글 변환의 한계 (알려진 거친 부분)

발음 표기는 "한국인이 읽어서 일본어에 가깝게 들리도록" 하는 근사이며, 언어학적으로 정확하지 않습니다.

- **장음**: `ー`(및 `pronunciation`의 장음)는 `-`로 표기합니다. 예) `コーヒー` → `코-히-`, `当然` → `토-젠`.
  `そう`처럼 표기상 `-`가 붙는 것이 자연스럽지 않아 보이는 경우도 있습니다.
- **촉음 っ**: 앞 음절에 `ㅅ` 받침으로 붙입니다. 예) `そっと` → `솟토`, `待って` → `맛테`, `ずっと` → `즛토`.
- **ん**: 뒤 자음에 따라 받침을 고릅니다. `カ/ガ`행 앞 → `ㅇ`(`音楽` → `옹가쿠`), `マ/パ/バ`행 앞 → `ㅁ`,
  그 밖에는 `ㄴ`(`こんや` → `콘야`, `えん` → `엔`). `ん`이 독립 토큰으로 잡히면 후처리로 앞 음절에 합칩니다
  (`思い出したんだ` → `오모이다시탄다`). 단, `ん` 바로 앞이 장음(`ー`)이면 붙일 자리가 없어 홑자모가 남을 수 있습니다(희귀).
- **요음**: `きゃ/しゃ/ちゃ` 등은 `캬/샤/차`로 매핑합니다. 다만 `じゃ/じゅ/じょ`는 기존 수동 데이터의 표기
  관행에 맞춰 `쟈/쥬/죠`로 냈습니다(일반적인 외래어 표기 `자/주/조`와 다름).
- **조사**: `は`(→`와`), `へ`(→`에`), `を`(→`오`)는 kuromoji의 `pronunciation` 값이 이미 반영하고 있어 자동 처리됩니다.
- **숫자 + 조수사**: `2人`, `1口`처럼 아라비아 숫자에 붙은 counter 한자는 사전이 읽음을 주지 않아
  `2닌`, `1쿠치`처럼 나옵니다. (수동으로 `후타리`, `히토쿠치` 등으로 고쳐야 합니다.)
- **드문 고유명사·한자**: 사전에 읽음이 없으면 해당 한자를 그대로 남깁니다(희귀).
- **띄어쓰기**: 형태소 경계로 어절을 나누되 조사·조동사·접미사·비자립어는 앞말에 붙입니다.
  `～する`(サ変) 결합도 붙입니다. 보조동사가 이어지면(`絡めあっていく`) 붙어서 `카라메앗테이쿠`처럼
  한 덩어리가 될 수 있습니다. 의미 전달에는 지장 없지만 수동 표기와 띄어쓰기가 다를 수 있습니다.
- **라틴 단어**: `orig` 안의 `flight`, `Oh right` 같은 ASCII 단어는 `pron`에 그대로 둡니다.

`trans`는 무료 웹 번역기 결과라 어색하거나 존댓말/반말이 섞일 수 있습니다. 초안으로만 쓰고 검수하세요.
